# Healthcare Claims Processing & Multi-Language Translation Platform

An end-to-end Google Cloud application that ingests healthcare claims PDFs (itemized medical bills with or without coding, insurance cards, policy details, proof of payment, medical records, referrals, and prior authorizations), stores them in **Google Cloud Storage**, extracts layout via **Google Cloud Document AI**, immediately detects the document language, conditionally translates non-English documents to English via **Google Cloud Translation API v3 Advanced (`translate_document`)** while preserving the original PDF layout, provides a **Side-by-Side Original vs. Clean English Comparator** in the UI, extracts structured CMS-1500 ready claims data using **Gemini 3.8 Flash** (`google-genai` Interactions API), and persists records in **Firebase / Cloud Firestore**.

## Required Configuration (`TODO` Checklist Before Running)

All project-specific identifiers (Google Cloud Project ID, Project Number, Cloud Storage bucket name, Document AI Processor ID, and Firebase project alias) are kept out of version control via [`.gitignore`](.gitignore) in `.env.gcp` and `.firebaserc`.

### Step 1: Create `.env.gcp` from `.env.gcp.example`
```bash
cp .env.gcp.example .env.gcp
```

Open `.env.gcp` and complete the clearly marked `TODO` items:
1. **`GCP_PROJECT_ID=TODO_YOUR_GCP_PROJECT_ID`** *(Required)* — Replace with your Google Cloud Project ID (e.g., `my-healthcare-claims-project`).
2. **`GCP_PROJECT_NUMBER=TODO_YOUR_GCP_PROJECT_NUMBER`** *(Optional if running `./deploy.sh`)* — Replace with your numeric project number (`gcloud projects describe $GCP_PROJECT_ID --format="value(projectNumber)"`), or let `./deploy.sh` resolve and write it automatically.
3. **`GCS_BUCKET_NAME=TODO_YOUR_GCS_BUCKET_NAME`** *(Optional if running `./deploy.sh`)* — Replace with your globally unique Cloud Storage bucket name, or leave as `TODO_*` so `./deploy.sh` provisions `${GCP_PROJECT_ID}-claims-docs` automatically.
4. **`DOCAI_PROCESSOR_ID=TODO_YOUR_DOCAI_PROCESSOR_ID`** *(Optional if running `./deploy.sh`)* — Replace with your Document AI `OCR_PROCESSOR` ID, or let `./deploy.sh` provision/discover the processor and write its ID into `.env.gcp` automatically.
5. **`GEMINI_API_KEY`** *(Optional)* — Leave commented out when using Application Default Credentials (ADC), or set if authenticating to the Gemini API via an explicit API key.

### Step 2: Create `.firebaserc` from `.firebaserc.example` (Optional if running `./deploy.sh`)
```bash
cp .firebaserc.example .firebaserc
```
Replace `"TODO_YOUR_GCP_PROJECT_ID"` inside `.firebaserc` with your `GCP_PROJECT_ID` (note: `./deploy.sh` also generates `.firebaserc` automatically from `GCP_PROJECT_ID`).

## Quick Start (Idempotent Setup & Run)
```bash
# 1. Authenticate with Google Cloud
gcloud auth login
gcloud auth application-default login

# 2. Copy and configure .env.gcp (set GCP_PROJECT_ID)
cp .env.gcp.example .env.gcp

# 3. Provision GCP APIs, GCS bucket, Firestore, Document AI, Python venv, and deploy to Cloud Run
./deploy.sh --cloud-run

# 4. Run end-to-end tests across English, Spanish, French, and Korean
.venv/bin/pytest tests/test_pipeline.py -v

# 5. Start the web application locally on http://127.0.0.1:8001
.venv/bin/uvicorn backend.main:app --host 127.0.0.1 --port 8001
```
